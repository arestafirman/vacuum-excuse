# 14 Laps Around One Chair Leg

Entry for [The Robot Vacuum's Funniest Excuse](https://make.fun/c/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2) on [make.fun](https://make.fun).

A robot vacuum explains, in one line, why it missed a spot: it circled the same chair leg 14 times today, its own map now calls the leg a landmark, and the dust underneath calls it home.

Two beats: the setup (14 laps around one chair leg) and the payoff (the map made it official — a landmark — and the dust moved in).

`main.ts` writes the single line to `/output/entry.txt` — no trailing newline, no extra text.
